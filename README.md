# React Dashboard Project

## Project Setup with Docker Compose

This project is a React Dashboard application with TypeScript, Tailwind CSS, and Vite. It is containerized using Docker Compose.

### How to Run the Project

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Adityoexs/interactive-desktop-react
   cd react-dashboard
   npm install
   npm run dev

2. Docker Compose:
   ```bash
   git clone https://github.com/Adityoexs/interactive-desktop-react
   cd react-dashboard
   npm install
   docker-compose up --build
